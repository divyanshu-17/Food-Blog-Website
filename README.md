# 🍽️ Food Atlas

Food Atlas is a modern and responsive food blog & recipe browser built using **HTML, CSS, and JavaScript**.  
It allows users to explore delicious recipes, search dishes instantly, filter meals by cuisine or category, and view complete recipe details — all inside a lightweight static website with no backend required.

---

## ✨ Features

- 📱 Fully responsive food blog layout
- 🍛 Beautiful recipe cards with:
  - Images
  - Cuisine type
  - Category
  - Cooking time
  - Difficulty level
- 🔍 Instant recipe search
- 🧭 Filter recipes by cuisine and meal type
- 📖 Recipe detail section with ingredients & instructions
- ⚡ Lightweight static website (No backend needed)
- 🛠️ Easy recipe management through a single JavaScript file
